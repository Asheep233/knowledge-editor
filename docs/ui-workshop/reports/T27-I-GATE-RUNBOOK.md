## 1. 执行步骤（U1–U6，对齐 T27-installer-upgrade-plan.md）

- **U1 基线安装**：在干净 VM 安装旧版（如 1.2.9）→ 启动 → 确认版本/无错误 → 记录。
- **U2 覆盖升级**：安装候选 1.2.18 → 检查已安装路径/版本/数据未丢（测试数据自建）→ 启动正常。
- **U3 升级后功能**：工作区打开、编辑保存、打印、工坊入口（如启用）冒烟。
- **U4 回滚**：卸载 1.2.18 后重装旧版（或使用安装器回滚路径）→ 数据仍可打开 → 版本回退正常。
- **U5 卸载**：卸载候选版 → 程序目录清理、**用户数据按产品策略保留**（检查 `%APPDATA%`/工作区）。
- **U6 重启与恢复**：升级/回滚后重启 2 次 → 无 crash/recover 异常；单实例正常。

## 三、用户可感知的功能/防御修复

| 修复 | 影响 |
| --- | --- |
| 目录名含 `_`/`%` 时改名会误删兄弟目录索引且重启不自愈 | 改名后搜索/列表不再丢文件（LIKE 转义） |
| 中文多词搜索恒 0 结果（如 `公式 渲染`） | 多词搜索按 AND 语义命中（LIKE 交集兜底） |
| Windows 上「只改大小写」的重命名/移动被拒或提示冲突 | 正常改名；磁盘/索引均使用新大小写 |
| 文档包导出漏掉含空格/括号/角括号/URI 编码的附件引用 | 跨设备导入不再缺图 |
| 导出 PDF 预览不反映所选颜色/浅深主题（预览≠导出） | 预览即导出效果 |
| 外部修改提示出现后自动保存仍会覆盖外部版本 | 冲突弹窗期间暂停自动保存；「保留本地」才立即落盘 |
| 右栏属性面板未保存的标题/标签在切档时静默丢失 | 纳入未保存语义；切档前自动提交旧文档 |
| 1280px 下工具栏右侧按钮被裁切、键盘焦点让整页横移 | 工具栏自身横向滚动、正文区不横移 |
| 桌面 release 仍信任开发端口 `localhost:5173` 来源 | 生产模式收紧为仅 tauri 来源 |
| 畸形 zip 返回 500；NUL 路径个别端点 5xx | 统一为可读 4xx |
| `build.ps1` 读不到后端版本导致构建中止；`start.ps1` 版本不一致告警静默失效 | 构建/启动脚本恢复可用与可信 |

- 深色 PDF 打印仍较费墨（可用「浅色」主题导出）；页边距/纸张大小/批量导出未做（沿用 v1.2.12 范围）。

- 平台相关少量 skip 用例保留（Windows 专有路径/权限场景在对应 CI job 覆盖）。

## 附：发版前真机验收清单（Windows / WebView2）

1. 安装包底栏显示的前端/后端版本一致，无「版本不一致」告警。
2. 有未保存修改时：关闭窗口 / 重载（Ctrl+R）→ 出现应用内确认，取消不丢失、确认才继续。
3. 外部修改冲突：另一程序改文件 → 弹窗出现期间不自动覆盖；「保留本地」落盘 /「重新加载」取磁盘版本。
4. PDF 导出：自定义浅色/深色与文字色 → 预览与导出文件颜色一致；导出后文档 sha256 不变、工作区零写入。
5. Windows 大小写不敏感场景：`Hello.md → hello.md` 改名/移动成功，索引与树显示新名称，无临时文件残留。
6. 目录名含 `_` 的改名后，兄弟目录搜索/列表仍在（BE-06 老缺陷回归）。
7. 中文输入法组词：工作区路径回车、脚注回车、属性保存回车不误触发。

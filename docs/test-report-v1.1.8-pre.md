## 6. 缺陷清单

### S1（已修复并复验）：应用退出后侧车残留（孤儿进程占端口）

- **现象**：关闭主窗口后 `knowledgeeditor-backend.exe` 仍存活（2 个进程），主侧车继续占用 `127.0.0.1:8000`。
- **影响**：下次启动可能与陈旧后端交互（工作区/索引状态不一致）；端口资源泄漏。
- **根因**：v1.1.6 关窗假死修复把清理放进了**分离线程**并立即 `app.exit(0)` —— 主进程在侧车被 kill 之前已退出。
- **修复**：清理改为**同步但有界**（`taskkill /F /T` + 1.2s 预算）后再退出：
  - `sidecar.rs`：`GRACEFUL_WAIT` 5s → 1.2s，优雅 kill → force/tree kill
  - `menu.rs`：`request_exit` 分离线程 → 同步调用
- **复验**：关窗退出 **2.6s**（<6s 门槛，无假死回归）· 侧车残留 **0** · 8000 端口释放 · 单实例/二次启动正常。
- **提交**：v1.1.7 分支后续提交（随 v1.1.8 发布）。

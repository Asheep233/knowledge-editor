## 相对 v1.3.0-pre.4 的变化

### 1. 关窗挂起加固（真机审查 P2-1）
- 现象（审查发现）：CDP 调试会话异常终止等 WebView2 异常场景下，关窗后窗口消失、后端已清理，但主进程可能 >20s 不退出。
- 加固：退出第二阶段启动 **8s 硬超时 watchdog**，到点写诊断日志 `%APPDATA%\KnowledgeEditor\runtime\exit-watchdog.log`
  并 `process::exit(0)` 强制结束。正常退出进程先结束，watchdog 不会触发；对普通用户无行为变化。

### 2. 跨工作区最近文档隔离（真机审查 P3-4）
- 现象：切换工作区后，知识库「最近编辑/继续写作」与 ⌘K「最近文档」仍显示其它工作区文档，点击 404。
- 修复：两处都按**当前工作区文件树**过滤最近文档；启动恢复 `ke.lastArticleId` 遇到 404 时自动清除陈旧 id。
- 附带：新增跨工作区过滤回归测试。

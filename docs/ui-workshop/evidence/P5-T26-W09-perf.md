## 解释与限制（必须一并阅读）

- 512KB fixture 为**公式密集**（每段含 `$...$`），Editor 对公式节点渲染开销大；W09 压力场景本就极端；
- CDP 逐字符 `Input.insertText` 存在 round-trip 开销，但 ~1s/字符仍显著偏高，疑似大文档 React 重渲染/公式渲染阻塞；
- 256KB 文档首次未打开（字符 0）：可能是列表交互/加载超时，与 60s 测量期间 CDP 调用变慢叠加；
- guest 启用 81s 未成功：发生在 512KB 文档仍处于重负载时，不能单独归因；
- 以上为**真实产品环境证据**，结论是：**W09 当前未达标，需要性能剖析与优化（大文档/公式/懒加载/渲染节流）**，
  在优化与更严谨基准（P0 同机基线）前不得宣称 W09 通过。

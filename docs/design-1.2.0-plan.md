## 3. 由裁决派生的实现约束

- **项①**：默认映射为空（全部沿用现状）；设置三处同步（`settings.ts` → IPC → `settings.rs` 结构体 + `from_value_lenient` 白名单 + `sanitize`）；深合并 → 解绑用**墓碑值**；补 2 条「三处不同步」守门测试；保留键（原生菜单 `Ctrl+N/O/,/Q/R`、`F12`）不可绑定或明确警告。
- **项②**：规范已先行（`design-v1.1.7-math-editor.md` §3.2 已按第 5 条重拍）；只读态**必须**加 `isEditable` 闸门（既有漏洞：`isEditable=false` 时 PM 命令仍会改文档）。
- **F-1…F-5**：需先补规范条款（换行策略 / BOM 容忍 / 行内 HTML 与实体保真 / 任务列表语法归属），再改代码；修改点集中在 tokenizer / 序列化 / `stripFrontmatter`。
- **Tab 栏**（第 4 条）：新增 App 层「打开文档集合」状态 + `EditorToolbar` 既有 `tabBar` 插槽；需覆盖脏态、切换前 flush（复用 `docSwitch` 缝）、关闭、顺序、与快捷键 `doc.next/prev` 集成。
- **源码模式**（pre.2）：字符串直存**完全绕开 ProseMirror**；**单视图排他**；切回正文时提示「原文中的未知语法可能被规范化」；frontmatter 隐藏；`<textarea>`；视图态**全局**；切换前自动 flush。

## 1. ① 常用公式模板

### 1.1 形态（2026-09-08 主理人修订）
- **模板入口 = 全屏公式编辑器（§3）右侧常驻模板面板**；工具栏「模板 ▾」**取消**
- 全屏模态成为**公式编辑的统一入口**：点击现有公式 / Ctrl+N / Ctrl+M / 工具栏公式按钮
  → 都弹出全屏模态（§1 与 §3 合并实现为「公式编辑体验」模块；补全（§2）同样在模态源码框内生效）
- 面板：右栏常驻（<720px 自动折叠为图标）；点击模板 → 骨架入源码框 + 光标落槽

### 1.2 模板集（v1 内置，后续可配置化）

| 模板 | 骨架（`□`=槽位） | 槽位数 |
|---|---|---|
| 方程组 | `\begin{cases} □ \\ □ \end{cases}` | 2 |
| 多行对齐 | `\begin{aligned} □ &= □ \\ □ &= □ \end{aligned}` | 4 |
| 矩阵 | `\begin{pmatrix} □ & □ \\ □ & □ \end{pmatrix}` | 4 |
| 行列式 | `\begin{vmatrix} □ & □ \\ □ & □ \end{vmatrix}` | 4 |
| 分段函数 | `\begin{cases} □, & □<x≤□ \\ □, & \text{其他} \end{cases}` | 3 |
| 常用单式 | `\frac{□}{□}` `\sqrt[n]{□}` `\sum_{□}^{□}` `\int_{□}^{□}` | 各 2 |

### 1.3 槽位协议（编辑态内部协议，不进存储）
- 槽位字符：`□`（U+25A1）作为内部锚点标记；**保存/失焦时从 LaTeX 移除**（strip 函数）
- 槽位栈：插入模板时记录槽位序列（按出现顺序），Tab 前进/Shift+Tab 回退；引擎 = §2.2
- 与 Markdown 存储无交互：节点属性里永不含 `□`（保存前清理；极端残留时后端/解析层忽略）

## 2. ② 公式自动补全（VS Code 式）

### 2.1 交互
```
输入 \fr → 300ms 防抖后悬浮建议（光标下方，输入框正下方列表）
  ├── \frac{}{}        ★ 常用（带槽）
  ├── \frac            （纯命令）
  ├── \frac{\sqrt{x}}{y}
  └── \frac{1}{2}      模板扩展
↓/↑ 浏览 · Tab 选中插入 · Esc 关闭 · 失焦/输入清空建议隐藏 · Enter 不消费（保持换行语义）
```

### 2.2 候选数据源
- 内置 **KaTeX 常用命令白名单**（~120 条，高频优先；按前缀实时过滤）
- 叠加 §1 模板（带槽位的骨架项标记 ★）
- 触发条件：textSelection 前一个非空白字符 = `\` + 至少 1 个字母

### 2.3 设置开关
- `settings.editor.mathAutocomplete: boolean`（默认 **true**）
- 传递链：前端 schema（normalizeSettings）→ Rust `EditorSettings` 字段 + `from_value_lenient`
  **白名单必须同步**（上轮教训：漏加 = IPC 返回 null）
- 关闭后：Tab 无补全行为、无建议面板；模板按钮功能不受影响（模板与补全是两个开关独立的入口，
  本开关仅管"输入时悬浮建议+Tab 选择"）

### 2.4 选中后
- 插入骨架 + 光标落到第一个槽（后续 Tab = 槽位跳转，§1.3）；纯命令项插入后光标在末尾

## 3. ③ 全屏公式编辑器（知乎式）

### 3.1 形态
```
fixed inset-0 z-90；外圈 rgba(0,0,0,0.45) 半透明
┌─ 居中卡片（max-w-720，块级公式更高）────────────────────┐
│  [源码输入框]         （大号等宽，Tab 补全/槽位）        │  ← 右侧模板面板
│  [KaTeX 实时预览]     （大号居中，错误显示友好提示）      │     （常驻，可收）
│  可视化模式切换 · Enter=换行 · Esc=保存/空删除 · 完成    │
└─────────────────────────────────────────────────────┘
```

### 3.2 规则（主理人已拍板）
| 项 | 决策 |
|---|---|
| 外圈点击 | **不关闭**（防误触丢修改）|
| 关闭 | Esc（保存/空删除语义沿用）· 「完成」按钮 |
| 复用 | MathNodeView 现有编辑态 UI 迁移为模态；保存后光标回到文档原型位置 |
| 行内/块级 | 共用模态；块级卡片加高（textarea rows 3）；模板面板两者恒显 |
| 存储 | 无变化（节点 attrs 不变）|

### 3.3 实现要点
- 模态挂 EditorContent 外层（React portal）；textarea 全键盘体系（补全/Tab/Enter/Esc）由
  MathNodeView 逻辑内聚（单组件，避免焦点风暴——v1.1.6 已踩过坑）
- 输入框非受控（v1.1.6 光标复位教训）

## 附：实施修正记录（2026-09-08 · 与设计的偏差）

| 设计 | 实施 | 原因 |
|---|---|---|
| 模态由 MathNodeView 渲染（portal）| **上移至 EditorArea（编辑器根）** | nodeview = tiptap 独立 React 根，模态内触发 PM 事务 → React #300（叉掉/保存白屏）；编辑器根与工具栏同根，事务安全 |
| 保存按节点 pos 定位 | **按节点 id 遍历 doc 定位**（pos 兜底）| mount 期 getPos 可能过期，导致保存落空/误改 |
| 「空公式自动弹窗」 | 改为**插入路径显式派发**（openMathEditorById）| Ctrl+Z 撤销回空内容会误触发弹窗 |
| 模板入口含工具栏下拉 | 仅模态内面板 | 主理人修订（2026-09-08）|

以上均已落地并通过 GUI 验收（含用户实测批次）。

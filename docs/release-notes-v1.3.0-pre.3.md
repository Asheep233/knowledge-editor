# AstraNota v1.3.0-pre.3（预发布）

> **预发布版本**：正式版仍为 `v1.2.18`（Latest）。本版在 `v1.3.0-pre.2` 基础上把**命令条与参考前端逐项对齐**，
> 并包含 pre.2 的两个修复（源码模式编辑框塌陷 / 导出 PDF 卡顿）。文档格式与工作区结构无变化。

## 相对 v1.3.0-pre.2 的变化：命令条对齐参考前端

对照参考实现（`AstraNota-Focus-Handoff` 的 `.format-bar`）逐项修正：

| 项 | pre.2 | pre.3（对齐参考） |
|---|---|---|
| 撤销/重做 | 在左侧可滚动格式组内（窗口窄时会被滚走） | **移到最右侧固定组**（`format-end`，始终可见；源码态整组禁用） |
| 列表 | 单图标按钮弹菜单 | 参考稿 `tb-split`：主按钮=无序列表切换，`▾`=无序/有序/清除 |
| 公式 | 两个独立 Σ 按钮（行内 + 块级方框） | 参考稿 `tb-split`：主按钮=行内公式，`▾`=行内/块级 |
| 保存状态 | 命令条内有独立「⊙ 已保存」chip | **移除**（参考稿无；保存态保留在专注模式顶栏） |
| 导出按钮 | 带 `▾` chevron | 去掉 chevron（参考稿 `btn-outline`，点击仍展开导出菜单） |
| 保存按钮 | 描边样式 | 参考稿 `btn-secondary` 浅底无边框 |
| 分隔线 | 部分分组缺分隔 | 按参考稿分组：正文后 / 链接后 / 引用后 / 公式后 / 插入后 / 撤销重做前 / 保存前 |

## 包含 pre.1 / pre.2 的全部 Focus UI 内容与修复

- Focus UI 全面对齐（浮动侧栏/居中纸面/浮动命令条/知识库·搜索·模块·资料·回收站整页/⌘K 命令面板/设置独立页/文档信息浮层/历史 sheet/专注模式等）；
- pre.2 修复：源码模式编辑框塌陷（66px → 498px）、导出 PDF 卡顿（4 万节点文档对话框打开 >30s 冻结 → 567ms，生成期无副本爆炸）。

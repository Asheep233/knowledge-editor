# AstraNota v1.3.0-pre.6（预发布）

> **预发布版本**：正式版仍为 `v1.2.18`（Latest）。本版相对 pre.5：
> ① **启动看门狗**（真机「双击图标没反应」事故处置）；② **恢复保存状态显示**（用户实测反馈）；③ **编辑器右侧竖向滚动条**（用户要求）。其余同 pre.5。

## 相对 v1.3.0-pre.5 的变化

### 1. 启动看门狗：杜绝「双击没反应的无窗口僵尸」
- 事故（2026-10-24 真机）：Modern Standby 刚恢复后双击桌面图标，进程与 sidecar 都已启动，但 **WebView2 初始化挂起、主窗口从未创建** —— 用户看到「没反应」，再次双击只会触发单实例回调（找不到窗口），只能在任务管理器结束进程。8 次干净重启均 0.5s 出窗口（一次性环境异常）。
- 处置：进程启动即拉独立 watchdog（纯 Win32 轮询，不依赖可能被卡住的 Tauri 事件循环）：
  - 30s 内检测到可见主窗口 → 正常，watchdog 退出；
  - 用户触发关窗握手中 → 让路；
  - 窗口存在但隐藏/最小化 → 尝试恢复并在日志记录；
  - **窗口根本不存在 → 写 `runtime/startup-watchdog.log` + 原生错误框提示 + 自动退出**，用户重新双击即可重试，不再留下僵尸进程。

### 2. 恢复保存状态显示（用户实测「保存状态不见了」）
- pre.3 为对齐参考稿移除了命令条里的「已保存」chip，导致保存状态不可见、手动保存后没有反馈（按钮本身可用）。
- 现在命令条右下方常驻状态：`✓ 已保存`（空闲/已保存）、`未保存…`（有改动）、`保存中…`、`保存失败`；保存按钮增加按压反馈。状态采用**绝对定位**，不占命令条横向宽度（避免再次挤压「插入」按钮）。

### 3. 编辑器右侧竖向滚动条（用户要求）
- 此前为「纸面不横向位移」隐藏了正文滚动条；现新增**自绘滚动条**：固定在窗口最右侧（用户明确要求「在右边」）、常驻可见、可拖动 thumb、可点击轨道跳转；不占正文列宽，不依赖 Windows「自动隐藏滚动条」策略。
- 无溢出时自动隐藏；打印态隐藏；新增几何计算单测与验收断言（滚动后 thumb 同步下移）。

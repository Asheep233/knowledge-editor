# AI Agent 协作声明

本项目（KnowledgeEditor）的开发过程包含 AI Agent 协作，特此声明，保证透明度。

## 协作方式

- 架构设计、功能实现、测试编写、构建脚本与项目文档，均由项目所有者给出指示，AI Agent 在本地开发环境中辅助完成。
- Agent 产出的每一份代码与文档都经项目所有者审阅、实测验证后合入（git 提交可追溯）。
- 关键决策（架构选型、冻结基线、发布版本等）由项目所有者确认，Agent 不单方决定。

## 协作范围

| 环节 | 说明 |
| --- | --- |
| 代码实现 | 前端（React/Tiptap）、后端（FastAPI）、桌面化（Tauri 侧车 / 设置系统 / NSIS 打包），逐里程碑交付并实测 |
| 测试 | 单元测试（pytest / vitest）、回归矩阵、安装验收、构建验证 |
| 文档 | 阶段报告、架构设计（`docs/phase0-architecture.html`）、开发日志（`CHANGELOG_DEV.md`）、README 等 |
| 构建与发布 | 安装包构建、GitHub Releases 分发 |

## 透明度与数据主权

- 全部开发过程记录于 `docs/` 阶段报告与 `CHANGELOG_DEV.md`（开发日志），每一条变更均可回溯到具体提交。
- 用户文档与数据仅存于本机，Agent 协作不改变数据主权承诺：Markdown 文件是唯一事实源，SQLite 索引可整体重建。
- 开发在本地环境进行，不依赖任何云服务；用户实测是迭代质量的最终判据。

## 时间范围

- 初始开发：2026-08-08 ~ 2026-08-11（Phase 0 架构设计 → v1.0.0 发布，进入 Alpha 测试期）。
- 后续迭代：v1.x.y Alpha 版本继续以「用户实测反馈 + Agent 协作」的方式推进，阶段状态见 `PROJECT_STATE.md`。

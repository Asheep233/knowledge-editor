# AstraNota v1.2.18（修复 v1.2.17「导出」按钮无反应回归）

> **状态：已发布（v1.2.18，Latest）** —— https://github.com/Asheep233/knowledge-editor/releases/tag/v1.2.18
> 发布依据：主理人 2026-10-18 批准；流程按 `docs/release-policy.md` 执行（bump → 构建 → 安装包真机验收 → Release）。
> 本文即 GitHub Release 正文来源（已做本机路径卫生检查）。

**建议升级（仅影响 v1.2.17 用户）。** 本版修复一个由 v1.2.17 引入的界面回归：**点击工具栏「导出」按钮无任何反应**。

## 问题与根因

- **现象**：v1.2.17 中点击编辑器工具栏「导出」按钮，下拉菜单不出现，看起来像按钮失灵；导出 PDF / 文档包 / Markdown 等入口全部无法使用。
- **根因**：v1.2.17 为修复「窄窗口下工具栏右侧按钮被裁切」（UI-01），把**整条**工具栏根节点设为横向滚动容器（`overflow-x-auto`）。
  导出按钮的下拉菜单是工具栏内 `absolute` 定位的子元素 —— 会被滚动容器**裁剪**，菜单实际渲染但不可见。
- **修复**：横向滚动范围收缩到**左侧格式控件**；右侧（保存状态 / 视图切换 / 历史 / 导出）改为固定区块，下拉菜单不再被裁剪。
  UI-01 的修复目标（窄视口可横向滚动、键盘焦点不再推动正文整页横移）保持不变。

## 验证

| 项 | 结果 |
| --- | --- |
| 真机（Windows / WebView2，修复后构建） | 点「导出」→ 菜单正常显示（174×30，视口内可命中）→ 点「导出 PDF」成功打开导出对话框 |
| 窄视口 1100px 复验 | 左侧格式控件可横向滚动（799 > 523）；导出按钮固定可见；正文容器 scrollLeft = 0（不横移） |
| 结构回归测试（新增） | 真实渲染工具栏，断言导出按钮不在横向滚动容器内、祖先链无裁剪容器（同类回归会直接失败） |
| 全量门禁 | vitest **104 files / 1576 passed + 1 skipped**（exit 0）；tsc 0；pytest / cargo 未改动 |

## 真实浏览器验证

使用 Playwright 与系统 Chromium，在独立的 `/workspace/.knowledge-editor-cloud/data/workspace` 中创建唯一测试文档，没有读写用户的正式笔记。

已验证：

- SDK、contract、包校验、非法 CSS/JS/函数字段拒绝；预览不写盘、取消与自动超时。
- 界面颜色、字体、字号、圆角、两侧栏宽度与导航右置实际生效。
- 外观切换前后的 ProseMirror DOM 为同一节点；正文计算样式、根 CSS tokens 不变。
- 富文本编辑、Ctrl+S、源码切换、源码编辑与保存仍走原路径；文档内容可从后端读回。
- 原有主题设置仍可操作，包内浅/深色方案分别生效；重载后恢复保存的外观。
- 默认恢复、上一包回滚、JSON 导出与 `?appearance=off` 恢复入口。
- PDF 预览计算样式与打印媒体样式不受外观包影响，并输出 Chromium PDF 检查。
- 自定义属性栏宽度后收起只保留展开按钮，中央区域释放对应空间，重新展开可用。此项发现并修复了初版规则给外层属性栏固定宽度的问题。
- 预览时设置暂时隐藏但组件与 JSON 草稿保留，主界面可见；独立确认条可取消或保留 SDK 当前预览包，到期后自动返回设置。确认条在打印媒体下隐藏。
- 既有 API smoke：字节保真保存、中文全文搜索、索引重建、附件读回、回收站与恢复通过。

上述浏览器检查未出现 pageerror。截图及临时脚本位于本次执行环境 `/workspace/scratch/appearance-browser-*`，属于验证产物，不随应用打包。

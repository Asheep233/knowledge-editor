## 相对 v1.3.0-pre.3 的修复

### 1. 命令条「+ 插入 ▾」按钮被裁掉一半（pre.3 回归）
- 现象：命令条右端的「插入」按钮被横向滚动容器裁切（1440 窗口溢出 12px；1280 窗口溢出 142px，几乎整颗按钮看不到）。
- 根因：pre.3 把撤销/重做移到右侧固定组后，左侧格式组内容仍宽于可用空间；`overflow-x-auto` 在容器右缘直接裁掉最后一个按钮。
- 修复：① 格式组去掉 item 间距（gap 2px→0）、收窄内边距；② **≤1400px 视口**启用紧凑规则：图标按钮 32→22px、隐藏分组竖线、保存/导出收成图标 —— 常见窗口宽度下格式组均不溢出、末端按钮完整可见。
- 实测：1440 / 1366 / 1280 / 1200 / 1100 / 1024 / 900 / 800 八档宽度全部 `overflow=0`、插入按钮完整可见（修复前 1280 档裁切 140px）。

### 2. 块级公式 `\tag` 编号叠在公式上（历史遗留 bug）
- 现象：`$$L = \mathbb{R} \tag{1}$$` 的编号 `(1)` 与公式本体**重叠**，而不是排在正文列右端。
- 根因：KaTeX 的 `.katex-tag` 是 `position:absolute; right:0`，锚定最近的定位祖先；此前块级公式渲染容器是 `display:inline-block`（宽度收缩到公式内容宽）→ tag 右边界落在公式右缘，与正文重叠。
- 修复：块级公式渲染容器改为占满正文列宽（`display:block; width:100%`），与 KaTeX 官方 display math 容器一致。
- 实测（1440×900）：块 680px、渲染容器 680px；`(1)` / `(S.1)` 右对齐于列右端（距右缘 4px），与公式本体无重叠。
- 回归防护：新增 `MathNodeView.tagLayout.test.tsx`（结构：`.katex-tag` 存在且文本正确；样式契约：块级容器必须 `display:block + width:100%`），并纳入全量测试。
